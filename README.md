# ソノサポ（Sonography × Support）

全国の医学生のための、エコー学習とエコー部づくりの応援アプリ（PWA）。
和歌山県立医科大学 K-PICS のアプリをもとに、全国展開用に作り直したものです。

- 公開までの手順：**[SETUP.md](SETUP.md)**
- 画面：GitHub Pages（このリポジトリのファイル）
- データ・ログイン・画像・PDF：Supabase（守っているのは Supabase 側の RLS とトリガー）

## 参加のしくみ
- 82大学それぞれに、招待コードが2つ（部員用・確認者用）
- コードを1回入れれば、その端末では次から自動でログイン（匿名ログイン）
- 管理者だけはメールアドレス＋パスワード

## 注意
- `service_role` キーは絶対にコードへ書かない
- 新しい表を作るときは RLS をオンにし、`public.is_member()` などで鍵をかける
