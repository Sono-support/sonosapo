最初の1回だけ、ここで鍵を作り、PUSH-SETUP.md の手順で Supabase に登録します。鍵を作り直すと、全員がもう一度「通知を受け取る」を押す必要があります。

読み込み中

資料につけるラベルです。名前・色を変えると、すべての資料に反映されます。ラベルを消すと、資料からも外れます。

招待コードの配り方
各大学の「部員用」コードはエコー部の代表者へ、「確認者用」コードは指導医の先生へ渡してください。「招待リンクをコピー」を使うと、コードが入った状態で開くリンクを送れます。


コードが外に漏れたら
「作り直す」を押すと、古いコードは使えなくなります（すでに参加している人はそのまま使えます）。


まなぶの資料
まなぶタブの右上「編集」から、項目の追加・並べ替え・削除、資料（PDF・画像・リンク）の追加とラベル付けができます。


お知らせ
ホーム右上のベルから、全国の参加者にお知らせを出せます。


管理者を増やす
Supabase の SQL Editor で、SETUP.md の「管理者アカウントを作る」の手順をもう一度行ってください。
